Steps

  1. Select the link in the following table (column 1) to determine if the specific benefit or allowance you provided is taxable. If the benefit or allowance is taxable, you have to include the value in your employee's income.

    Overview: What is a taxable benefit

  2. Parissa's Notes about the table

It is always best not to put links in a any table header as it get "read" for each cell, after the type of link is mentioned. However, it is not strictly a WCAG fail on it own, but it is a very poor user experience for non-vidual readers.

In the case of this particular table, there should be absolutely not be a link in the headers, because the table is made sortable, and the sorting buttons are links also, and it is too confusing. This is why you would have been told you cannot put a link the in the header of this table.

So as a rule, avoid links in headers. If you really must, the table must not be a dynamic (sortable), AND, it should be a proper footnote denoted by a number, not an asterisk. The coding of the footnote minimizes the text "read" for each cell. For example: "Header text same page link Footnote 1"

The footnote section can be placed at the bottom of the section it references to reduce distance from the content when applicable. If it applied only to one table, at the bottom of that tables. If multiple tables at the bottom of the last table, or appropriate section. Otherwise at the bottom of the page.

For this table, the sortin appears to not be necessary. We could remove the sorting funtionality.

The table should (or any other content should never be full width in a subway page. However, since we don't have a better suggestion for you at this time, we will keep it as is until we can do something else. Just wanted you to be aware of this as you design other pages.

Situation: Only remuneration provided is a taxable benefit

If the only remuneration provided is a taxable benefit, do not deduct CPP contributions if both of the following conditions apply:

  • It is a non-cash taxable benefit (with the exception of security options)
  • It is the only remuneration you provide to your employee (your employee did not receive any cash earnings)
